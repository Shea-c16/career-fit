# CareerFit · 岗位适配助手

帮助求职者将真实经历与岗位要求对应，查看证据、改写对照与网申回答草稿。

**当前状态：已支持离线示例与可选 DeepSeek 真实分析。默认可免费查看虚构示例；真实分析需用户自行配置 API Key，并手动确认后才会调用。**
示例人物、公司和岗位均为虚构，结果人工编写，页面显式标注。没有邮件、招聘官网或账户权限依赖。

## 本地运行

Python 3.9–3.13：

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

Windows 激活方式：`.venv\Scripts\activate`。在此项目目录执行命令。
浏览器访问终端显示的本地地址。点击“载入虚构示例”，再点击“查看示例分析”。

## 已实现

- 可编辑的简历 / JD 双输入；用户更新资料后旧结果失效。
- 岗位要求逐项证据展示、缺失信息提示。
- 原文和建议改写对照，不覆盖输入。
- 有字符统计的开放题草稿。
- 下载 Markdown 报告。
- 原文引用存在性校验与基本自动测试。

## 边界

当前示例结果仅适用于内置输入，不会对任意输入套用固定分析。
引用存在不等于结论正确，仍需人工核对。没有录用概率或匹配分。
不自动投递、不生成 PDF、不持久化个人资料、不进行网络模型调用。
以后启用 API 时需明确告知数据发送对象与费用，再由用户主动运行。

## 更新：可选真实分析

现已增加 `live_analysis.py`，以上有关“尚未接入模型”的旧版说明仅对应离线初版。
在本机 `.streamlit/secrets.toml` 设置 `DEEPSEEK_API_KEY`（此文件已忽略，禁止提交）。
页面勾选发送与计费确认后，点击“开始真实分析”，才会请求 DeepSeek。
使用 `deepseek-flash` 非思考模式，单次输出上限5000 Token；无自动重试。
真实输入将发给 DeepSeek；服务端不主动写入磁盘，结果暂存在页面会话中。
返回内容需通过结构、回答长度与原文引用校验，校验失败仍可能产生调用费用。
真实结果包含基础资料、匹配证据、改写和回答草稿，支持 JSON 导出。
已完成模拟接口和页面检查；尚未完成付费端到端测试及真实模型质量评测。
官方接口文档：https://api-docs.deepseek.com/api/create-chat-completion/
